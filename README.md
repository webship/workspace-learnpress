# @webship.co/workspace-learnpress

LearnPress, the learning management plugin of WordPress, for the [Webship Workspace](https://github.com/webship/workspace)
dashboard: a builder that makes a real WordPress site with LearnPress in containers, its tool, the default accounts and
a sample course, the LearnPress step pack wired into the workspace's testing setup, and its AI items.

The builder, the tools, the tests and CI come with the first release, `1.0.0`.
